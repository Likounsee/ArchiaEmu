# Supported systems

## Current verified status

**No console is currently implemented or supported.** The repository contains shared contracts only; they are not an emulator.

| System | Status | Evidence |
| --- | --- | --- |
| None | No implementation | No concrete CPU, bus, peripherals, or console test suite exists yet |

## Status definitions

- **Planned:** selected as a future target; no working core.
- **Experimental:** core code exists but behavior is incomplete or unverified.
- **Boots tests:** starts some documented test content.
- **Partially functional:** defined test subset passes, with documented gaps.
- **Validated compatibility:** a published test suite and method pass reproducibly.
- **Extended compatibility:** broad representative corpus and regression suite results are published.

A crate name, successful compilation, or GUI entry does not count as support. Future entries must identify test-suite provenance, versions/hashes where licensing permits, expected results, actual results, and known failures.
